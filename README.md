# Verona Cinematic Residence

A luxury 3D WebGL showcase built with React, Three.js (@react-three/fiber), GSAP, and Vite.

## Features
- Interactive 3D Architecture & Interior Visualization
- Smooth Scrolling & Animations with Lenis & GSAP
- High-Performance WebGL Shader Effects & Custom Lighting

## Getting Started

```bash
npm install
npm run dev
```
